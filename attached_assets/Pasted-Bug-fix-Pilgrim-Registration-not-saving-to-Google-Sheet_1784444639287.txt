Bug fix: Pilgrim Registration not saving to Google Sheet
File to edit: scripts/pilgrim.js
Problem: Pilgrim registration form submits but data is not appearing in the Google Sheet "Pilgrims" tab.
Step 1 — Diagnose first, don't fix blindly:
Check the following and report back before making any changes:

Find the fetch/POST call in scripts/pilgrim.js — what URL is it posting to? Is it using PILGRIM_GAS_URL or GAS_URL or something else?
Check if token: 'kumbh2027secure' is included in the POST body
Check if action: 'registerPilgrim' is in the POST body
Open browser DevTools console, submit the form, and report any errors
Check what response comes back from GAS — add a temporary console.log(result) after the fetch and report what it prints

Step 2 — Fix based on diagnosis:
The most likely issues are:

Wrong GAS URL being used
Missing token: 'kumbh2027secure' in POST body (will get Unauthorized response)
Missing action: 'registerPilgrim' in POST body

Make sure the POST body includes ALL of these:
javascript{
  action: 'registerPilgrim',
  token: 'kumbh2027secure',
  id: pilgrimId,
  name: name,
  age: age,
  gender: gender,
  city: city,
  contact1: contact1,
  contact2: contact2 || '',
  medical: medical || '',
  photo: photoBase64 || '',
  timestamp: timestamp
}

Step 5 — Filter My Pilgrims by signed-in user:
Find the "My Pilgrims" section rendering code. Update it to only show pilgrims where UserEmail matches the signed-in user's email:
javascriptfunction loadMyPilgrims() {
  if (!KumbhAuth.isSignedIn()) return;
  var userEmail = KumbhAuth.getUser().email;
  
  var saved = JSON.parse(localStorage.getItem('myPilgrims') || '[]');
  var myPilgrims = saved.filter(function(p) {
    return p.userEmail === userEmail;
  });
  
  renderMyPilgrims(myPilgrims);
}
