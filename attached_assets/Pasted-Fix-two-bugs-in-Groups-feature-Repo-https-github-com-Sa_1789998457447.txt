Bug 2 — Group info lost when app is closed

Currently when user closes and reopens the app, their group code and member name are gone so they have to rejoin.

Fix by saving group info to localStorage when user joins or creates a group, and restoring it on page load.

When user creates or joins a group, save to localStorage:

javascript
localStorage.setItem('kumbh_group', JSON.stringify({
  groupCode: currentGroup,
  memberName: currentMember
}));

When groups page loads, restore from localStorage:

javascript
function initGroups() {
  // Restore saved group info
  var saved = localStorage.getItem('kumbh_group');
  if (saved) {
    try {
      var parsed = JSON.parse(saved);
      if (parsed.groupCode && parsed.memberName) {
        currentGroup = parsed.groupCode;
        currentMember = parsed.memberName;
        // Skip the join/create screen and go straight to group view
        showGroupView();
        startGroupTracking();
        loadGroupMembers();
      }
    } catch(e) {
      localStorage.removeItem('kumbh_group');
    }
  }
}

When user leaves the group, clear localStorage:

javascript
localStorage.removeItem('kumbh_group');

Make sure initGroups() is called when the groups page is shown/navigated to.

Also check:

currentGroup and currentMember variables are properly set before saving
showGroupView() function exists — if it has a different name, use the correct function that shows the active group screen (hiding the join/create form)
Group tracking interval restarts correctly on restore
